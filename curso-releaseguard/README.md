# ReleaseGuard AI — materiais da aula

Este diretório foi reorganizado para separar apresentação, guias, atividades, projetos executáveis, validações e ferramentas.

## Comece aqui

1. Abra o deck revisado: [`01_apresentacao/aulas_3_dias_SCTEC_REVISADO.pptx`](01_apresentacao/aulas_3_dias_SCTEC_REVISADO.pptx).
2. Leia a visão geral: [`02_guias/geral/00_guia_geral_3_dias.md`](02_guias/geral/00_guia_geral_3_dias.md).
3. Prepare o laboratório: [`02_guias/geral/00_setup_ambiente_completo.md`](02_guias/geral/00_setup_ambiente_completo.md).
4. Em cada dia, use primeiro o guia de implementação/condução e depois o exercício mentorado.
5. Consulte as notas do apresentador no PPTX: todos os 81 slides contêm a condução completa e as fontes complementares do dia.
