# Entrega dos trios

Cada trio deve entregar:

1. Código do agente.
2. README do use case.
3. Comandos para rodar.
4. Exemplo de entrada.
5. Exemplo de saída estruturada.
6. Demonstração de dry-run.
7. Demonstração de bloqueio sem aprovação.
8. Se executar ação real, demonstrar aprovação e audit log.
9. Trace LangSmith ou explicação de como habilitar.
10. Decisões de segurança e limitações.

## Critérios de comparação

- O agente resolve um problema oneroso para humano?
- O uso de tools é necessário e justificado?
- A ação perigosa foi protegida?
- Existe idempotência?
- Existe tratamento de falha?
- Existe saída estruturada?
- A auditoria é suficiente?
- A apresentação compara antes/depois?
