# Política do catálogo de tools

## Contrato
Toda tool precisa de nome específico, tipos, docstring, escopo e comportamento de falha.

## Escrita
Tools de escrita ficam fora do agente deste módulo.

## Retry
Retries devem ser limitados e apenas para falhas transitórias. Repetir a mesma busca sem reformulação é ausência de progresso.
