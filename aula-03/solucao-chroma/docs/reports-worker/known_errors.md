# Catálogo de erros conhecidos do reports-worker

## E-440
Falha de credencial no object storage.

## E-550
Consulta excedeu o timeout do analytics-db.

## E-771
Código reservado, ainda sem causa documentada. Não existe procedimento aprovado. Colete tamanho, formato, tenant e trace; escale para engenharia.

## QUEUE-LAG
Condição operacional associada a backlog, não necessariamente erro de execução.
