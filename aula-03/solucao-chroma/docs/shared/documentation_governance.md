# Governança da base técnica

## Vigência
Somente documentos com `is_current=true` podem orientar ação operacional.

## Confiança
`authoritative` e `validated` podem sustentar evidências. Fontes `unverified` servem apenas como pista para nova investigação.

## Ambientes
Documentos específicos de staging não devem ser usados para recomendar ações em produção.

## Versão e citação
Toda evidência deve registrar arquivo, heading e versão.
