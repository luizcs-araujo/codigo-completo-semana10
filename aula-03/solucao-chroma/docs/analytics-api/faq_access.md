# FAQ de acesso ao dashboard

## O usuário está autenticado, mas recebe 403
Autenticação e autorização são etapas diferentes. Confirme o recurso e a role autorizada.

## Recarregar a página resolve?
Pode mascarar convergência temporária, mas não corrige divergência persistente.

## Posso pedir restart?
Restart não é procedimento aprovado para 403 de autorização. Use o runbook vigente.
