# SLO do checkout

## Objetivos
Disponibilidade mensal de 99,95% e p95 abaixo de 800 ms.

## Alertas
Se 503 superar 5% por cinco minutos, abrir incidente. Se superar 10% com p95 acima de dois segundos, acionar on-call.

## Uso pelo agente
O SLO ajuda a classificar severidade, mas não identifica causa raiz sozinho.
